FAQ

Questions, answered

Answers about installing and using the tweaks.

Installation

Getting an app onto your iPhone

How do I install on a jailbroken device?

Add the source in Sileo, Zebra, Cydia or Installer — the Add the source button does it in one tap — then search for the app and install it. The right build for rootless, rootful or roothide is picked for you.

How do I install without a jailbreak?

Use a signing app. In KSign, Feather, Scarlet or ESign, add the source link for signing apps (on the Install page) and install from there — or download the IPA from the app's page and open it in your signing app. For AltStore and SideStore there is a dedicated link on the Install page.

Can I use TrollStore?

Yes. Each app has a TrollStore build (.tipa) that keeps the app's own extensions and entitlements. TrollStore supports iOS 14.0 beta 2 – 16.6.1, 16.7 RC and 17.0.

Which iOS version do I need?

The jailbreak builds work on iOS 14 and later. For the IPA, it depends on the version of YouTube or TikTok inside it — each app's page shows the exact minimum.

Using the apps

Where things are and how they work

Where are the settings?

ASJTube has its own tab in YouTube's bar. ASJTok opens from its own row in the profile menu, under ASJ tools; its options are in the long-press menu too.

Which languages are supported?

ASJTube speaks all 79 languages YouTube ships in, and ASJTok all 53 of TikTok's. Each follows the app's own language, right-to-left included.

How do I update?

Updates arrive through the source you added: your package manager or signing app shows the new version when you refresh it. New releases are also posted on the Telegram channel.

Privacy

What happens to your data

Do the apps collect any data?

No. There are no accounts and no ASJ servers. A few optional features reach an outside service only when you use them — they are listed in the Privacy Policy.

Do I need an account?

No. Nothing to sign up for and nothing to log into.
