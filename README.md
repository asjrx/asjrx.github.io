# ASJRX

A Sileo / Zebra / Cydia source for my tweaks.

```
https://asjrx.github.io/
```

| Package | What it is |
|---|---|
| **ASJTikTok** | Privacy, download and playback options for TikTok — [details and screenshots](https://github.com/asjrx/ASJTikTok) |

Not jailbroken? Each tweak ships a dylib you can inject into your own copy of the
app; see that tweak's page.

<sub>Adding a package: drop the .deb into `debs/`, run `python3 make-index.py`, commit and push.</sub>
