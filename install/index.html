Install

How do you install apps?

Pick yours and follow the steps — most take one tap.

Add the source

SileoZebraCydiaInstaller

In any app not listed, copy the link and add it under Sources:

https://apt.ahmadrashed.com/

Then

  1. Refresh your sources.
  2. Search for ASJTube or ASJTok and install it.
  3. The build for rootless, rootful or roothide is chosen for you. Updates arrive the same way.

Add the source

KSignFeatherScarlet

In any app not listed, copy the link and add it under Sources:

https://source.ahmadrashed.com

Then

  1. Open the source and pick the app.
  2. Choose no extensions if your certificate is limited; it works with any certificate.
  3. Sign and install. New versions appear in the source.

Prefer the file? Download the IPA from ASJTube · ASJTok

Add the AltStore source

AltStoreSideStore
https://altstore.ahmadrashed.com

Good to know

  1. AltStore and SideStore get the build without extensions — the one a free Apple ID can sign.
  2. Apps signed with a free Apple ID expire after 7 days; AltStore refreshes them for you.

Install with TrollStore

  1. Open the tweak's page and tap Download.
  2. Under TrollStore, tap Install — TrollStore opens and installs it.
  3. It keeps the app's own extensions, so notifications and widgets keep working.
